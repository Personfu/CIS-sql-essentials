# Appendix B: Installing MySQL Software (MacOS)

1. Download the MySQL DMG archive from the official MySQL website.
2. Open the DMG and run the installer package.
3. Follow the prompts to install MySQL Server and MySQL Workbench.
4. Set a root password and remember it for future use.
5. Complete the installation and launch MySQL Workbench.

---

For troubleshooting, see the official MySQL documentation or contact support.
