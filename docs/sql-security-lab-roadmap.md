# SQL Security Lab Roadmap

This repo can support FLLC learning by turning database fundamentals into safe security education.

## Free modules

- ERD and relationship review.
- Least-privilege role design.
- Parameterized query explanation.
- Audit table design.
- Backup and recovery checklist.

## Basic member modules

- SQL report writing worksheet.
- Toy injection detection lab using static sample logs.
- Access-control matrix template.

## Premium modules

- Interactive database risk dashboard.
- Synthetic incident timeline with query logs.
- Guided remediation lab: from vulnerable toy query to parameterized safe query.

## Boundary

Teach SQL risk and remediation. Do not publish exploit chains for real targets or instructions for dumping, bypassing, or damaging databases.
