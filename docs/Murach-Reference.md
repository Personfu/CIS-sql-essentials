# Murach's MySQL Reference

This course is aligned with the textbook: *Murach's MySQL Training & Reference, 4th Edition*.

The reference PDF is included in the repository root as:

- `Murach's MySQL_ Training & Reference 4ed.pdf`

Use this textbook as:

- a reference for SQL syntax and MySQL features,
- a source for examples, quizzes, and exercises,
- a guide for deeper study beyond the automated module tasks.

Each `module-XX` folder in the repository is designed to provide automated, hands-on practice that complements the Murach textbook content.
