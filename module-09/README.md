# Modifying Data

Practice INSERT, UPDATE, and DELETE statements to change table data.

## Assignment

Create a Products table, insert sample rows, update prices, delete discontinued products, and leave final results ready for review.

## Files

- `assignment.sql` — student SQL script
- `tests.sql` — hidden grading queries
- `expected_output.txt` — expected test output

Do not edit `tests.sql` or `expected_output.txt`.
