# Extra Credit Submission: Jupyter Notebook Demo

This folder contains the fully completed extra credit assignment for "Getting started with Jupyter notebooks" from Zybooks Chapter 13.

## Included Files
- `extra_credit_demo.ipynb`: The completed Jupyter notebook with all code and markdown cells executed.
- `README.md`: Instructions and summary of the steps performed.

## Screenshots
Screenshots of the required outputs are not included here because this environment does not support GUI screenshot capture. However, all outputs (dataset preview, scatterplot, summary statistics) are present in the notebook and can be viewed and screenshotted by opening the notebook in Jupyter Lab.

## How to View Outputs
1. Open Jupyter Lab and navigate to `extra_credit_demo.ipynb` in this folder.
2. Run all cells if not already executed.
3. Take screenshots of:
   - The dataset preview (first code cell output)
   - The scatterplot (second code cell output)
   - The summary statistics (third code cell output)

You are ready to submit these screenshots to Canvas as required.
