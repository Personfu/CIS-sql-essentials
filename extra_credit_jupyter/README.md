# Jupyter Notebook Setup Instructions

This notebook demonstrates the steps for getting started with Jupyter notebooks as described in Zybooks Chapter 13 extra credit assignment.

---

## Step 1: Install Required Packages

From your terminal, run the following commands (if not already installed):

```
python -m ensurepip --default-pip
pip install jupyter
pip install notebook
pip install seaborn
```

---

## Step 2: Launch Jupyter Lab

From your terminal, run:

```
jupyter lab
```
